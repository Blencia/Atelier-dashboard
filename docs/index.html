Atelier

Le nouvel onglet devient une feuille de travail que tu construis toi-même. Chaque dossier de favoris devient un module qu'on déplace et redimensionne.

Essayer l'aperçu Code source Confidentialité

Ce que ça fait

  • Chaque dossier de favoris devient un module — tuiles, liste ou liste dense
  • Navigation dans les sous-dossiers sans quitter le tableau de bord
  • Recherche instantanée dans tous les favoris avec la touche /, avec repli sur le moteur de ton choix
  • Modules additionnels : horloge, bloc-notes, sites fréquents
  • Mode plan : glisse pour réordonner, tire un coin pour redimensionner

Personnalisable

  • Thème encre ou papier, couleur d'accent au choix
  • Colonnes, espacement, hauteur des rangées, arrondi des coins
  • Fond d'écran, densité, taille des icônes
  • Export et import de la mise en page en JSON

Confidentialité

  • Aucun compte, aucune inscription
  • Aucune requête réseau, aucun analytique, aucune publicité
  • Tout reste dans ton navigateur
  • Tes favoris sont lus, jamais modifiés
